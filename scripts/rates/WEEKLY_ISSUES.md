# 주간 금리 이슈 작성 지침 (Claude 예약 작업용)

매주 월요일 아침, 숫자 자동 갱신(06:30 KST)이 끝난 뒤 이 지침대로 **이번 주 주요 이슈 카드**를 쓰고 PR로 올린다.
사람이 PR을 확인하고 합치면(merge) 사이트에 반영된다. **main에 직접 푸시하지 않는다.**

---

## 1. 이번 주 숫자 확인 (가장 먼저)

1. `rates/data/latest.json` 을 연다.
   - `asof` 가 **지난 영업일**(오늘 한국시간 기준 바로 전 평일, 월요일이면 지난 금요일)이 아니면 숫자 갱신이 아직 안 된 것이다.
     이 경우 글을 쓰지 말고 "숫자 갱신 전이라 중단"이라고 보고하고 끝낸다.
     (예약이 07:30·08:30 두 번이라, 첫 번째에서 중단돼도 두 번째에 다시 시도한다.)
   - `asof` = 이번 기준일(지난 영업일). 파일명과 글의 기준은 모두 이 날짜다.
2. 다음 중 하나라도 해당하면 중단한다(같은 주 중복 방지):
   - main 에 `rates/data/issues/{asof}.json` 이 이미 있다.
   - `git ls-remote --heads origin claude/issues-{asof}` 결과가 있다(이미 PR을 올려 확인을 기다리는 중).
3. 각 그룹(`groups[].items[]`)에서 `change_bp`(금리, bp) / `change_pct`(지수·환율, %)가 큰 것을 골라 **이번 주 숫자 변화 메모**를 만든다.
   - 기준금리 변화가 있으면 무조건 다룬다.
   - 대략 기준: 국채·회사채·여전채 ±5bp 이상, CP ±3bp 이상, 저축은행 평균 ±5bp 이상, 코스피·코스닥 ±3% 이상, 환율 ±1% 이상.
   - 추세가 궁금하면 `rates/data/history.json` 의 최근 4~8주를 본다.
   - 금융채 발행(은행채·여전채 발행액, 여전채 발행금리와 민평 차이)은 `rates/data/issuance.json` 의 마지막 주를 본다. 발행이 크게 늘거나 발행금리가 민평보다 크게 높으면 `크레딧` 카드 재료가 된다.

## 2. 원인과 일정 찾기 (웹 검색)

- 기간: **지난 기준일 다음 날 ~ 이번 기준일** (`prev_asof` 다음 날부터 `asof` 까지).
- 1에서 고른 움직임마다 "왜 움직였는지"를 뉴스·공식 발표에서 찾는다.
  우선순위: 한국은행·기획재정부·금융위원회·금융감독원 보도자료, 연준·ECB·BOJ 발표, 그다음 주요 언론(연합뉴스, 한국경제, 매일경제, 이데일리, 연합인포맥스, Reuters, Bloomberg 등).
- **다음 주 일정** (기준일 다음 월요일 ~ 일요일):
  1. 하나증권 월간 '증시 이슈캘린더'에서 먼저 뽑는다. 그 주가 걸친 달의 PDF를 받아 글자로 꺼내 준다:
     ```bash
     pip install -q pypdf
     python scripts/rates/hana_calendar.py {다음주 월요일} {다음주 일요일}
     ```
     PDF 표가 풀리면서 칸 순서가 섞여 있으니, 날짜 칸을 따라 그 주 날짜의 항목만 골라낸다.
  2. 금리·채권 보고서에 필요한 것만 3~8개 고른다: 중앙은행 회의·의사록·베이지북, 한국·미국·유럽·일본·중국 물가(CPI·PPI), 고용, GDP, 국고채 입찰, 한국 휴장일. 개별 기업 실적·학회·상장 일정은 빼되, 삼성전자 잠정실적처럼 시장 전체에 큰 것은 넣어도 된다.
  3. 금통위·FOMC·ECB·BOJ 날짜는 각 중앙은행 공식 일정으로 한 번 더 확인한다. 하나증권 PDF와 다르면 공식 일정을 따르고 PR 본문에 적는다.
  4. 날짜는 캘린더 표기대로 쓰되, 해외 일정은 `note` 에 "현지시간"을 적는다(미국 발표는 한국시간 다음 날 새벽인 경우가 많다).
  5. PDF가 아직 안 올라왔거나 못 받으면 공식 일정(한국은행 보도계획·연준·BLS 일정)으로 대신 찾고 PR 본문에 적는다.
  6. 출처 표기: PR 본문에 "다음 주 일정: 하나증권 증시 이슈캘린더(YYYY년 M월호) + 중앙은행 공식 일정"이라고 적는다. PDF 내용을 통째로 옮기지 않는다.

## 3. 카드 쓰기

- 카드 **3~5장**. 회사 주간 보고서에 그대로 넣어도 되는 수준으로 쓴다.
- 카테고리는 다음 중 하나: `정책` · `글로벌·시장` · `국내 채권` · `크레딧` · `예금·대출` · `증시·환율`
- 제목: 30자 안팎, 결론이 보이게. 이모지 쓰지 않는다.
- 요약: 2~4문장, 존댓말("~했어요"보다 "~했습니다/~입니다"를 기본으로, 딱딱하지 않게).
  "무엇이 → 얼마나(숫자) → 왜 → 앞으로 볼 것" 순서.
- `numbers`: 카드와 관련된 사이트 숫자 1~3개를 "국고채 3년 3.937% (▼6.9bp)" 형태로.
  **숫자는 반드시 `latest.json`/`history.json` 값을 그대로 쓴다.** 뉴스에 나온 다른 숫자(장중가 등)와 섞지 않는다.
- `sources`: 카드마다 1~3개, **실제로 열어서 확인한 기사·발표의 정확한 URL**. 사이트 대문 주소(예: https://www.bok.or.kr)만 적지 않는다.
- `headline`: 이번 주를 한 문장으로(50자 안팎). 홈 배너에 그대로 나간다.
- 하지 말 것: 매수·매도 권유, 확인 안 된 전망을 사실처럼 쓰기, 회사 이름·내부 정보 언급.

## 4. 파일 저장

`rates/data/issues/{asof}.json`

```json
{
  "asof": "2026-10-02",
  "written_at": "2026-10-05 07:40",
  "headline": "미국채 금리 급등과 일본 금리 인상, 국내 채권은 강세로 마감",
  "cards": [
    {
      "category": "글로벌·시장",
      "title": "미국채 10년 5.28%, 한 주 만에 17bp 상승",
      "summary": "…2~4문장…",
      "numbers": ["미국채 10년 5.28% (▲17bp)", "미국채 1년 4.46% (▼3bp)"],
      "sources": [{"title": "기사 제목", "url": "https://..."}]
    }
  ],
  "upcoming": [
    {"date": "2026-10-07", "title": "미국 9월 FOMC 의사록 공개", "note": "현지시간, 한국시간 10/8 새벽"},
    {"date": "2026-10-09", "title": "한국 휴장 (한글날)", "note": ""}
  ],
  "upcoming_source": "하나증권 증시 이슈캘린더(2026년 10월호) · 연준 공식 일정"
}
```

저장 후 반드시 검사한다:

```bash
python scripts/rates/check_issues.py rates/data/issues/{asof}.json
```

`OK` 가 나올 때까지 고친다(숫자 불일치·빈 출처·형식 오류를 잡아 준다).

## 5. PR 올리기

- 브랜치: `claude/issues-{asof}`
- 커밋 메시지: `주간 이슈 초안 ({asof} 기준)`
- PR 제목: `[확인 요청] 주간 금리 이슈 {asof} 기준`
- PR 본문: headline, 카드 제목 목록, 다음 주 일정 목록, 참고한 숫자 변화 메모(1-3).
- 이 파일 하나만 바꾼다. 다른 파일은 건드리지 않는다.
